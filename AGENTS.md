# Regras do Projeto — Portfólio Isabella

## Tecnologias
- HTML5 semântico
- CSS3 puro (sem frameworks)
- JavaScript puro (sem bibliotecas)

## Regras de desenvolvimento
- Não inventar informações pessoais, experiências, projetos ou links
- Não substituir referências visuais por templates genéricos
- Não alterar a identidade visual definida
- Não utilizar azul como cor de destaque
- Manter rosa e vermelho como cores principais
- Não adicionar figurinhas ou adesivos decorativos
- Não remover funcionalidades para simplificar
- Preservar a organização dos arquivos
- Utilizar HTML semântico e acessível
- Manter CSS organizado com variáveis
- JavaScript separado e bem documentado
